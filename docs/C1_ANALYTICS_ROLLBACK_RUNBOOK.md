# C1-T9 Этап D: Валидация аналитики и rollback

Дата: 2026-02-25  
Трек roadmap: `C1-T9`

## Цель

Проверить, что при закрытии/архивации города:
- блокируются новые операционные действия;
- исторические данные остаются доступными в отчетах;
- есть быстрый и безопасный путь отката.

## 1) Валидация аналитики (D-этап)

Запустить:

```bash
npm run validate:city-policy:analytics
```

Скрипт строит отчет:
- политики городов (`city-policies`);
- статус города в каталоге (`cities-catalog`);
- метрики по `users/events/eventsusers/payments` по каждой локации;
- контрольные проверки по `nrsk`.

Отчет: `docs/reports/city-policy-analytics-*.json`

## 2) Что проверять в отчете

Для `nrsk`:
- `allowRegistration=false`
- `allowEventSignup=false`
- `allowEventManagement=false`
- `allowLogin=true` (если бизнес-правило не изменено)
- присутствуют исторические данные (`events/payments > 0`), т.е. история не потеряна.

Для активных городов:
- операции остаются рабочими;
- метрики продолжают обновляться.

## 3) Smoke сценарии (ручные)

1. `/{location}/register`
   - для `nrsk` ожидаем блокировку с понятным сообщением;
   - для активных городов регистрация доступна.
2. `/{location}/events`
   - для `nrsk` нет новых действий записи/управления;
   - история доступна на чтение.
3. Login:
   - для `nrsk` вход действующих пользователей работает по текущей политике;
   - для активных городов без регрессий.

## 4) Rollback (быстрый)

Если обнаружена критичная регрессия:

1. Включить ограничение авторизации (`AUTH_DEV_ONLY_MODE=true`).
2. Через Dev UI (или `global/cities`) временно вернуть безопасные флаги:
   - `allowLogin=true`
   - `allowRegistration`/`allowEventSignup`/`allowEventManagement` по согласованному режиму.
3. Повторить:
```bash
npm run validate:city-policy:analytics
```
4. Проверить ручной smoke.
5. Зафиксировать инцидент и причину в changelog.

## 5) Критерий завершения C1-T9 D

- Отчет сформирован без ошибок.
- Проверки по `nrsk` соответствуют ожидаемой политике.
- Ручной smoke пройден.
- Откатный сценарий проверен на тестовом контуре.
