# Runbook: VK ID smoke и staged rollout

Дата: 2026-02-22  
Трек roadmap: `VK-T6`

## Цель

Безопасно включать VK ID по городам и контролировать регрессии в авторизации.

## Предусловия

- В VK приложении настроен `redirect URI` вида `https://<domain>/api/vk-id/callback`.
- На сервере доступны env:
  - `VK_ID_APP_ID`
  - `VK_ID_REDIRECT_URI`
  - при необходимости `VK_ID_DOMAIN`
- В Dev UI для города управляется флаг `allowVkAuth`.

## Smoke checklist (до включения в проде)

Для каждой локации (`krsk`, `nrsk`, `ekb`):

1. `allowVkAuth=false`
   - на `/{location}/login` VK виджет не отображается;
   - на `/{location}/register` VK виджет не отображается;
   - серверный вход через VK заблокирован guard-ом.
2. `allowVkAuth=true`
   - VK виджет отображается на login/register;
   - успешный вход для уже привязанного `vk_id`;
   - корректная ошибка при неуспешном обмене `code/device_id`;
   - вход через телефон/пароль и telegram не сломан.
3. Проверка recovery
   - сценарий `/{location}/recovery` работает как раньше (без зависимости от VK).
4. Проверка сессии
   - в сессии присутствуют `registrationType` и `authProviders`.

## Staged rollout

1. Включить `allowVkAuth=true` только для одного города.
2. Мониторить 24 часа:
   - долю ошибок авторизации,
   - долю отказов на login/register,
   - стабильность callback/exchange.
3. При стабильности включить второй город.
4. Затем третий город.

## Метрики контроля

- Успешность логина через VK.
- Конверсия `login/register` по городу до и после включения VK.
- Ошибки `CredentialsSignin` и backend ошибки VK exchange.
- Доля fallback на телефонный вход.

## Критерии stop/rollback

Немедленно откатывать (`allowVkAuth=false`) если:

- рост auth-ошибок > 20% к базовой линии;
- массовые жалобы на невозможность входа;
- ошибки обмена с VK носят системный характер.

## Откат

1. В Dev UI выключить `allowVkAuth` для проблемной локации.
2. Убедиться, что VK виджет пропал с login/register.
3. Проверить, что phone/telegram вход продолжают работать.
4. Зафиксировать инцидент и подготовить корректирующий патч.
