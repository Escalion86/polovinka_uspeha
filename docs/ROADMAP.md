Период плана: 15.02.2026-31.05.2026.
Фокус: позиционирование -> рост целевой аудитории -> рост выручки.

## Как пользоваться

- Этот файл — единый рабочий план по продукту.
- Статусы задач обновляются прямо здесь:
  - `[ ]` не начато
  - `[-]` в работе
  - `[x]` выполнено
  - `[*]` отложено
- При изменении roadmap обязательно:
  - обновить этот файл
  - обновить версию в `package.json` (patch/minor/major по масштабу изменений)

---

## Цели продукта (текущий фокус)

- Закрепить новое позиционирование: пространство живых встреч и легкого общения.
- Привлекать и расширять целевую аудиторию 30-50.
- Повысить конверсию в регистрацию через простой и понятный путь входа.
- Увеличивать повторные посещения и среднюю прибыль мероприятий.
- Подготовить базу для mobile-направления (PWA сейчас, React Native + Expo в следующем цикле).

---

## KPI периода

- Прирост новой аудитории (новые регистрации за месяц).
- Конверсия `посещение /<location> -> успешная регистрация`.
- Повторные посещения мероприятий.
- Средняя прибыль на мероприятие.
- Среднемесячное количество участников мероприятий.
