# Настройка блока "Закрытое пространство"

## Где настраивается
- Кабинет: `Сайт -> Закрытое пространство`
- Страница: `/{location}/cabinet/closedSpace`

## Что настраивается
- `Закрытое пространство`: выбор пространства из списка.
- `Подзаголовок`: заголовок блока на странице `/{location}`.
- `Описание`: текст блока на странице `/{location}`.

## Поведение на странице `/{location}`
- Блок `Закрытое пространство` показывается только если выбрано пространство.
- Если выбранное пространство имеет `showOnSite=false`, блок все равно показывается.
- В блоке `Наши пространства` карточки с `showOnSite=false` не показываются.
- Для выбранного закрытого пространства кнопка `Подробнее` в карточке (если карточка видима) не открывает модалку, а прокручивает к блоку `Закрытое пространство`.
- В самом блоке `Закрытое пространство` кнопка `Подробнее` открывает модалку с полным описанием выбранного пространства.

## Значения по умолчанию
- Подзаголовок: `ЗАКРЫТОЕ ПРОСТРАНСТВО ДЛЯ СВОИХ`
- Описание:
  `Это формат с камерными встречами, где мы собираем небольшие группы по ценностям. Здесь больше глубины, доверия и долгих разговоров. Доступ открывается после знакомства с командой и участия в открытых мероприятиях.`

## Валидация на сервере
- `closedSpace.directionId` сохраняется только если:
  - это валидный `ObjectId`
  - и такой `Directions._id` существует в текущей локации.
- Если значение невалидно, сохраняется `null`.
